# 四足机器人控制系统技术汇报

---

## 1. 功能介绍

### 1.1 主要功能
本项目实现了一套基于STM32F103C8微控制器的四足机器人控制系统，具备以下核心功能：

| 功能模块 | 功能描述 |
|---------|---------|
| **运动控制** | 支持前进、后退、左转、右转、站立、摇摆等多种动作模式 |
| **传感器集成** | 集成BH1750光照传感器、HC-SR04超声波测距、噪声传感器、红外离地检测 |
| **人机交互** | 通过串口指令控制，OLED实时显示系统状态 |
| **自主避障** | 自动模式下自动检测障碍物并转向躲避 |
| **离地检测** | 新增功能：通过红外传感器检测离地状态，触发摇摆动作 |

### 1.2 核心特性

1. **多自由度运动**：8个舵机（4个髋关节+4个膝关节）实现复杂步态
2. **双模式运行**：支持手动遥控模式和自动巡航模式
3. **实时状态监测**：OLED屏幕显示传感器数据和运行状态
4. **平滑过渡**：动作切换时采用过渡状态，避免机械冲击
5. **安全保护**：红外离地检测，机器人离地时自动摇摆提示

### 1.3 适用场景
- 教育演示与机器人教学
- 小型搬运与探索任务
- 智能玩具与娱乐应用
- 机器人运动控制算法验证平台

### 1.4 用户价值
- 提供完整的四足机器人控制方案
- 模块化设计，便于扩展新功能
- 代码结构清晰，易于理解和二次开发
- 传感器丰富，可实现多种智能行为

## 2. 实现原理

### 2.1 技术架构
系统采用模块化分层设计，主要分为以下几层：

```
┌─────────────────────────────────────────────────┐
│         应用层 (main.c)                         │
│  主循环、命令处理、动作调度、状态管理          │
└─────────────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────────────┐
│         硬件抽象层 (Hardware/)                  │
│  舵机控制、传感器驱动、输入输出、OLED显示      │
└─────────────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────────────┐
│         外设驱动层 (Library/)                   │
│  STM32标准外设库 (GPIO、TIM、USART、I2C等)     │
└─────────────────────────────────────────────────┘
```

### 2.2 系统核心模块设计

#### 2.2.1 主程序结构 ([main.c](file:///d:/Git_Project/robot/7-/robot_0/User/main.c))
主循环采用时间片轮询机制，通过`system_tick`计数器控制各任务执行周期：

```c
// 任务调度周期
- 500ms: LED闪烁指示
- 5ms:   串口命令处理
- 100ms: 传感器读取与显示更新
- 250ms: 舵机角度更新与动作执行
```

#### 2.2.2 舵机控制模块 ([Servo.c](file:///d:/Git_Project/robot/7-/robot_0/Hardware/Servo.c))
**技术选型依据**：
- 使用PWM控制舵机，TIM2和TIM3定时器产生50Hz PWM信号
- 舵机角度范围0-180°对应脉冲宽度500-2500μs

**控制公式**：
```
PWM比较值 = (角度 / 180) × 2000 + 500
```

#### 2.2.3 动作状态机
系统采用状态机设计，`action_state`变量控制当前动作：

| 状态值 | 动作名称 | 说明 |
|-------|---------|------|
| 0 | 站立 | 初始/复位状态 |
| 1 | 前进 | 四足交替迈步 |
| 2 | 后退 | 反向迈步 |
| 3 | 左转 | 左侧步态调整 |
| 4 | 右转 | 右侧步态调整 |
| 5 | 摇摆挥手 | 腿部左右摆动 |
| 6 | 深蹲 | 四肢弯曲 |
| 7 | 平躺 | 髋关节平放 |
| 8 | 抬腿 | 单腿抬起动作 |
| 9 | 挥手 | 腿部左右摆动 |

#### 2.2.4 离地检测与摇摆功能（新增）

**硬件配置** ([Input.c](file:///d:/Git_Project/robot/7-/robot_0/Hardware/Input.c))：
- 红外传感器连接PB7引脚，配置为下拉输入模式
- 按键连接PA0引脚，配置为上拉输入模式

**数据流程**：
1. 每100ms在`ReadSensors()`中读取红外传感器状态
2. 在`UpdateServo()`中检测`infrared_state`
3. 高电平触发摇摆状态，低电平恢复站立
4. 摇摆动作采用8步循环，通过`step_counter % 8`控制

**摇摆姿态序列**：
- 姿态0：左前右后倾斜
- 姿态2：左右平衡倾斜
- 姿态4：右前左后倾斜
- 姿态6：反向平衡倾斜

### 2.3 关键算法与数据流程

#### 2.3.1 步态生成算法
前进/后退步态采用四相位循环：
```
相位1 → 相位2 → 相位3 → 相位0 → 相位1...
  ↑        ↑        ↑        ↑
对角腿   左前后   对角腿   右前后
抬起     移     抬起     移
```

#### 2.3.2 避障逻辑
自动模式下，当超声波测距<15cm时：
1. 设置`obstacle_avoiding = 1`
2. 强制切换到左转动作
3. 障碍物消失后恢复前进

#### 2.3.3 动作过渡机制
当切换动作时（非复位/平躺）：
1. 进入过渡状态1 → 所有关节回中位
2. 进入过渡状态2 → 调整到站立姿态
3. 切换到目标动作状态

### 2.4 组件交互逻辑
1. **传感器→控制器**：I2C(BH1750)、GPIO(红外/按键)、定时器输入捕获(HC-SR04)
2. **控制器→执行器**：PWM输出到8个舵机
3. **控制器→显示**：SPI/I2C驱动OLED屏幕
4. **外部→控制器**：USART接收串口命令

## 3. 技术亮点总结

1. **高效的时间片调度**：无需RTOS即可实现多任务协调
2. **模块化设计**：硬件驱动与业务逻辑分离，便于维护
3. **丰富的运动库**：预设9种基础动作，可组合出复杂行为
4. **扩展性强**：预留了FreeRTOS框架，可支持更复杂的多任务
5. **新增离地检测**：提高了机器人的安全性和智能化水平
