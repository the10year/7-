# 四足机器人控制系统技术汇报

---

## 1. 功能介绍

### 1.1 主要功能
本项目实现了一套基于STM32F103C8微控制器的四足机器人控制系统，具备以下核心功能：

| 功能模块 | 功能描述 | 技术实现 |
|---------|---------|---------|
| **运动控制** | 支持前进、后退、左转、右转、站立、摇摆等多种动作模式 | 8路PWM舵机控制，状态机调度 |
| **传感器集成** | BH1750光照传感器、HC-SR04超声波测距、噪声传感器、红外离地检测 | I2C、GPIO、定时器输入捕获 |
| **人机交互** | 串口指令控制，OLED实时显示系统状态 | USART通信，SPI/I2C显示驱动 |
| **自主避障** | 自动模式下自动检测障碍物并转向躲避 | 超声波距离检测+动作切换 |
| **离地检测** | 红外传感器检测离地状态，触发摇摆动作提示 | PB7 GPIO输入检测 |
| **低光指示** | 光照低于阈值时LED1自动点亮 | BH1750数据判断+LED控制 |

### 1.2 核心特性

1. **多自由度运动**：8个舵机（4个髋关节+4个膝关节）实现复杂步态
2. **双模式运行**：支持手动遥控模式和自动巡航模式
3. **实时状态监测**：OLED屏幕显示传感器数据和运行状态
4. **平滑过渡**：动作切换时采用过渡状态，避免机械冲击
5. **安全保护**：红外离地检测，机器人离地时自动摇摆提示
6. **环境感知**：光照检测自动控制LED指示灯

### 1.3 适用场景
- 教育演示与机器人教学
- 小型搬运与探索任务
- 智能玩具与娱乐应用
- 机器人运动控制算法验证平台

### 1.4 用户价值
- 提供完整的四足机器人控制方案
- 模块化设计，便于扩展新功能
- 代码结构清晰，易于理解和二次开发
- 传感器丰富，可实现多种智能行为

### 3.2 主程序结构

主循环采用时间片轮询机制，通过`system_tick`计数器控制各任务执行周期：

```c
// 任务调度周期 (system_tick单位: ms)
- 1ms:   系统心跳计数
- 5ms:   串口命令处理
- 50ms:  离地检测状态更新
- 100ms: 传感器读取与显示更新
- 250ms: 舵机角度更新与动作执行
- 500ms: LED2闪烁指示
```

**核心变量说明**：

| 变量名 | 类型 | 作用 | 范围 |
|-------|------|------|------|
| system_tick | uint32_t | 系统时间计数器 | 0-4294967295 |
| action_state | uint8_t | 当前动作状态 | 0-9 |
| step_counter | uint16_t | 动作步数计数器 | 0-65535 |
| auto_mode | uint8_t | 自动/手动模式标志 | 0/1 |
| wave_state | uint8_t | 摇摆动作状态 | 0/1 |
| air_detect_state | uint8_t | 离地检测状态 | 0/1 |

### 3.3 舵机控制模块

**技术选型依据**：
- 使用TIM2和TIM3定时器产生50Hz PWM信号
- 舵机角度范围0-180°对应脉冲宽度500-2500μs
- 定时器时钟72MHz，预分频系数72-1，计数周期20000

**控制公式**：
```
PWM比较值 = (角度 / 180) × 2000 + 500
```

**舵机分配**：

| 舵机编号 | 控制关节 | 连接引脚 | 定时器通道 |
|---------|---------|---------|-----------|
| 1 | 左前髋关节 | PA0 | TIM2_CH1 |
| 2 | 右前髋关节 | PA1 | TIM2_CH2 |
| 3 | 左后髋关节 | PA2 | TIM2_CH3 |
| 4 | 右后髋关节 | PA3 | TIM2_CH4 |
| 5 | 左前膝关节 | PB0 | TIM3_CH3 |
| 6 | 右前膝关节 | PB1 | TIM3_CH4 |
| 7 | 左后膝关节 | PB5 | TIM2_CH3 |
| 8 | 右后膝关节 | PB4 | TIM2_CH4 |

| 状态值 | 动作名称 | 说明 | 步态周期 |

### 3.5 离地检测功能

**硬件配置**：
- 红外传感器连接PB7引脚，配置为上拉输入模式
- 检测周期：50ms

**工作原理**：
```
红外传感器输出：
  - 高电平(1): 检测到离地（反射光强低）
  - 低电平(0): 检测到着地（反射光强高）
```

**数据流程**：
1. 每50ms读取PB7引脚状态
2. 高电平触发摇摆动作（action_state=5）
3. 低电平恢复站立动作（action_state=7）
4. 设置`air_detect_state`标志防止重复触发

**代码实现**（[main.c](file:///d:/Git_Project/robot/7-/robot_0/User/main.c#L83-L99)）：
```c
if (system_tick % 50 == 0) {
    uint8_t ir_state = GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_7);
    if (ir_state == 1) {
        if (air_detect_state == 0 && action_state != 5) {
            air_detect_state = 1;
            action_state = 5;
            step_counter = 0;
            auto_mode = 0;
        }
    } else {
        if (air_detect_state == 1) {
            air_detect_state = 0;
            action_state = 7;
            step_counter = 0;
        }
    }
}
```

### 3.6 低光指示功能

**工作原理**：
- 光照传感器BH1750每100ms读取一次数据
- 当光照值低于10 lux时，LED1常亮
- 当光照值高于等于10 lux时，LED1熄灭

**代码实现**（[main.c](file:///d:/Git_Project/robot/7-/robot_0/User/main.c#L112-L116)）：
```c
if (lux_value < 10) {
    LED1_ON();
} else {
    LED1_OFF();
}
```

### 3.7 关键算法

#### 3.7.1 步态生成算法

前进/后退步态采用四相位循环：
```
相位1 → 相位2 → 相位3 → 相位0 → 相位1...
  ↑        ↑        ↑        ↑
对角腿   左前后   对角腿   右前后
抬起     移     抬起     移
```

**相位状态表**（前进动作）：

| 相位 | 左前髋 | 右前髋 | 左后髋 | 右后髋 | 左前膝 | 右前膝 | 左后膝 | 右后膝 |
|-----|-------|-------|-------|-------|-------|-------|-------|-------|
| 0 | 135 | 45 | 45 | 135 | 0 | 180 | 0 | 180 |
| 1 | 135 | 45 | 45 | 135 | 0 | 150 | 30 | 180 |
| 2 | 135 | 15 | 75 | 135 | 0 | 180 | 0 | 180 |
| 3 | 135 | 15 | 75 | 135 | 30 | 180 | 0 | 150 |

#### 3.7.2 避障逻辑

自动模式下，当超声波测距<15cm时：
1. 设置`obstacle_avoiding = 1`
2. 强制切换到左转动作（current_action=3）
3. 障碍物消失后恢复前进

**代码实现**（[main.c](file:///d:/Git_Project/robot/7-/robot_0/User/main.c#L186-L195)）：
```c
if (action_state == 1) {
    if (distance_value > 0 && distance_value < 15) {
        obstacle_avoiding = 1;
        current_action = 3;
    } else {
        obstacle_avoiding = 0;
    }
}
```

#### 3.7.3 动作过渡机制

当切换动作时（非复位/平躺）：
1. 进入过渡状态1 → 所有关节回中位（90°）
2. 进入过渡状态2 → 调整到站立姿态
3. 切换到目标动作状态

**过渡状态表**：

| 过渡状态 | 左前髋 | 右前髋 | 左后髋 | 右后髋 | 左前膝 | 右前膝 | 左后膝 | 右后膝 |
|---------|-------|-------|-------|-------|-------|-------|-------|-------|
| 1 | 90 | 90 | 90 | 90 | 0 | 180 | 0 | 180 |
| 2 | 135 | 45 | 45 | 135 | 0 | 180 | 0 | 180 |

## 5. 技术亮点总结

1. **高效的时间片调度**：无需RTOS即可实现多任务协调，资源占用低
2. **模块化设计**：硬件驱动与业务逻辑分离，便于维护和扩展
3. **丰富的运动库**：预设9种基础动作，支持复杂行为组合
4. **平滑过渡机制**：动作切换时自动过渡，避免机械冲击
5. **离地检测保护**：提高机器人安全性，防止摔落损坏
6. **环境感知能力**：光照检测自动控制LED，增强交互性
7. **扩展性强**：预留了FreeRTOS框架，可支持更复杂的多任务
